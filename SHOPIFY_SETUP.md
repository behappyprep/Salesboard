# Shopify connector setup for the ChannelPilot operator

ChannelPilot is a standalone, non-embedded app. A merchant enters the permanent `your-store.myshopify.com` domain in Connections, approves Shopify access, and returns to the existing ChannelPilot account. Do not request merchant passwords or manual Admin API tokens.

1. Open [Shopify Dev Dashboard](https://dev.shopify.com/dashboard) and create an app. Choose **public distribution** if this is intended for merchants outside your organization; it requires Shopify review before broad rollout. Use a permitted development store for testing first.
2. Configure **App URL:** `https://channelpilot-web.onrender.com`; **redirect URL:** `https://channelpilot-web.onrender.com/api/oauth/shopify/callback`; **embedded:** false. See `shopify.app.toml.example` for a sample configuration.
3. Request read-only scopes `read_orders,read_products,read_inventory`. Shopify's `read_orders` is limited to the last 60 days. Older history requires separately approved `read_all_orders`. Apply for the appropriate protected customer data access for order analytics; the connector does not request personal customer fields.
4. Configure Shopify's mandatory compliance topics `customers/data_request`, `customers/redact`, `shop/redact`, plus `app/uninstalled`, to the HTTPS endpoint `https://channelpilot-web.onrender.com/api/webhooks/shopify`. The app verifies raw-body webhook signatures and deletes store data when required.
5. In the Render web-service dashboard, add **secret environment variables** `SHOPIFY_CLIENT_ID` and `SHOPIFY_CLIENT_SECRET` from your Shopify app settings. Do not put these in GitHub, share them in chat, or add them to JavaScript. Render should automatically redeploy after updating environment variables.
6. Sign in to ChannelPilot → Connections → Shopify → enter the permanent myshopify domain → Connect → approve permissions. The OAuth callback validates the Shopify HMAC, checks a single-use state and the granted scopes, stores encrypted expiring offline and rotating refresh tokens, and begins an initial sync. The existing scheduler performs subsequent syncs.

The API imports the currently accessible Shopify order history and reads `InventoryItem.unitCost` for variants where the merchant has permission to view product costs. Those are **current cost estimates**, not necessarily historical unit costs. Actual payment fees, shipping expenses and historical FX are not automatically inferred, so contribution profit is marked incomplete when inputs are unknown. The pilot's free Render PostgreSQL database is temporary and must be upgraded and backed up before admitting real customers.
