# Salesboard / ChannelPilot

Multichannel merchant sales and contribution-profit dashboard pilot. This repository contains the application runtime archive in `runtime/` and a Render deployment blueprint. It is **not production-ready** for public customer onboarding. Shopify, Etsy and Faire integrations require app credentials; Amazon and Michaels use normalized CSV imports. Do not commit real credentials or customer exports.

See the prior deployment package for full source, tests and documentation. Never commit `.env` or API tokens.
